# Support

- **A question or an idea**: open an issue with the feature request form.
- **Something broken**: open an issue with the bug report form. It asks for the version, the
  operating system, the capture tier and the output of `footprints show <id>` where one applies.
- **An undo that went wrong**: stop and do not delete the data directory. Its ledger and blob store
  usually still hold the contents needed to recover. Open a bug report with the output of
  `footprints log --json` for the session, with any private paths removed.
- **Help by email**: support@isaacadjei.me
- **Anything else**: contact@isaacadjei.me or the [contact page](https://isaacadjei.me/contact).

> [!IMPORTANT]
> For a security issue, follow [SECURITY.md](SECURITY.md) rather than posting publicly.
