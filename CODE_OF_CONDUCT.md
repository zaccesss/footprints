# Code of Conduct

## Standards

Everyone taking part in this project, through issues, pull requests or discussions, is expected
to:

- Be respectful and constructive
- Give specific, helpful feedback rather than vague criticism
- Assume good faith, especially when a report describes lost work
- Keep other people's file contents, paths and logs private when sharing a bug report

## Unacceptable behaviour

- Harassment, abuse or personal attacks of any kind
- Spam or off-topic promotion
- Sharing anyone's private information without consent

## Enforcement

Report unacceptable behaviour to contact@isaacadjei.me or through the
[contact page](https://isaacadjei.me/contact). Reports are reviewed and acted on, which can include
removing comments or blocking accounts.

## Scope

This code of conduct applies to every interaction in this repository on GitHub.
